타자연습 프로그램
바이브코딩반 기획서
이 기획서는 AI에게 한 번에 넣어 작품을 완성하기 위한 설계도입니다. AI는 기획서에 적힌 것만 압니다. 처음 보는 사람이 이 기획서만 읽고 똑같은 작품을 만들 수 있을 만큼 자세히 쓰시오.
기획서는 팀전 기준입니다. [개인전] 표시가 있는 곳은 그 안내를 따르시오.
⚠ 다시 쓰게 되는 경우
아래 중 하나라도 해당하면 선생님이 기획서를 돌려줍니다. 검사를 통과해야 AI에게 넣을 수 있습니다.
•	쓰라고 한 항목을 빠뜨렸다
•	정해진 조건보다 짧거나 개수가 적다
•	"예쁘게", "재미있게", "적당히"처럼 사람마다 다르게 읽히는 말로 썼다
•	AI가 짐작해서 채워야 하는 부분이 있다 (위치, 크기, 숫자, 순서가 빠짐)
•	지난번에 만든 작품과 내용이 같다
•	한 사람에게 기획이 몰려 있다 [개인전: 해당 없음]

PART 4. AI에게 넣고 결과 기록하기
4-1. 한 번에 넣기
•	검사를 통과한 최종 기획서 전체를 AI에게 한 번에 넣으시오.
•	맨 앞에 "아래 기획서대로 만들어 줘. 기획서에 없는 것은 만들지 마."를 붙이시오.
•	넣기 전에 기획서를 나눠서 넣거나, 기획서에 없는 말을 덧붙이지 마시오.
4-2. 결과 기록
AI가 만든 작품을 2-7의 완성 기준으로 하나씩 확인하고 아래를 쓰시오.
•	한 번에 된 완성 기준 개수 / 전체 완성 기준 개수
•	안 된 완성 기준과, 기획서에서 그 부분이 어떻게 부족했는지
•	다음 기획서에서 더 자세히 쓸 부분
안 된 부분을 고칠 때는 AI에게 바로 "고쳐 줘"라고 하지 말고, 기획서의 부족한 부분을 먼저 고쳐 쓴 뒤 그 부분을 AI에게 넣으시오.
순서	만들 것	AI에게 할 말
1	시작 화면	"해달타자" 제목과 시작 버튼이 있는 화면을 만들어 줘. 또, 시작화면에 키보드 배경을 넣어줘 (대신 시작 버튼이 너무 안보이게 말고). 버튼을 누르면 다음 화면으로 넘어가게 해 줘.
2	칠 타자 선택	낱말연습 장문연습 선택권을줘
3	타자 내기	시작되면 오르쪽위에 스톱워치를 보여줘
낱말연습이면 한국어 낱말(말이되는) 아무거나 50개를 내줘.
장문연습이면 한국어 장문(말이되는) 아무거나 20개를 내줘.
4	정답 확인	타자를 입력하고 엔터를 누르면 맞았는지 틀렸는지 판단해줘. 만약 틀렸다면 삐소리를 내고 칠 글을 약간 1초동안 흔들리게 해줘. 만약맞았다면 소리없이 다음 문제를 내는데 글을 오른쪽에서 왼쪼으로 슬라이딩 하듯이 중간에 오게해줘.
5	끝 화면	만약 다끝났다면 ‘다끝났다’고 뜨고 얼마나 걸렸는지 알려줘
